📅 Day 1 — Core React Fundamentals

1. Components & JSX Syntax

React applications are built using JavaScript elements called components. JSX allows us to write HTML-like structures smoothly straight inside our JavaScript files.

import React from 'react';

function Welcome() {
  return <h1>Hello, Venudhar</h1>;
}

// Embedded JavaScript expressions inside templates using braces
function Greeting() {
  const name = 'Venudhar';
  return <h2>Welcome back, {name}!</h2>;
}

2. Props Integration

Props allow you to securely pass configurations or runtime values downstream from parent components into child nodes.

function UserCard({ name, role, onStatusChange }) {
  return (
    <div>
      <p>{name}</p>
      <p>{role}</p>
      <button onClick={() => onStatusChange('Active')}>Activate</button>
    </div>
  );
}

// Parent declaration: <UserCard name="Venudhar" role="Tech Lead" onStatusChange={handleStatus} />

3. Component State (useState Hook)

State encapsulates isolated values that belong specifically to a component. Updating this internal engine forces automated screen updates.

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      Count: {count}
    </button>
  );
}

4. Event Handling

React wraps native browser behaviors inside synthetic declarative wrappers (like onClick or onChange) to manage interactions predictably.

function SearchBox() {
  const handleInput = (event) => {
    console.log(event.target.value);
  };

  return <input onChange={handleInput} placeholder="Search..." />;
}

5. Conditional Rendering

Control flow conditions in React rely entirely on clean native JavaScript code structures (such as ternary operators or short-circuit statements).

function Status({ isLoggedIn }) {
  return (
    <div>
      {isLoggedIn ? <p>Welcome back!</p> : <p>Please log in.</p>}
    </div>
  );
}

6. Lists & Keys

Iterating over multiple data entries uses regular arrays mapped cleanly. Unique tracker key properties provide critical optimization signals to the framework engine.

function StockList() {
  const stocks = [
    { id: 1, symbol: 'ONGC', price: 270 }
  ];

  return (
    <ul>
      {stocks.map(stock => (
        <li key={stock.id}>{stock.symbol} — {stock.price}</li>
      ))}
    </ul>
  );
}

7. Controlled Forms

Controlled elements lock field text changes directly into the component's internal hook state storage, providing a unified source of data truth.

function LoginForm() {
  const [email, setEmail] = useState('');

  const handleSubmit = (e) => {
    e.preventDefault();
    console.log(email);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input value={email} onChange={(e) => setEmail(e.target.value)} />
      <button type="submit">Submit</button>
    </form>
  );
}

📅 Day 2 — Core Hooks & State Transformations

1. useEffect & Execution Cleanups

This hook manages external application adjustments (like network fetches, element bindings, or background timers). It also returns cleanup operations safely.

import { useEffect, useState } from 'react';

function StockPrice({ symbol }) {
  const [price, setPrice] = useState(null);

  useEffect(() => {
    // API call side-effect goes here
    return () => {
      // Optional connection or subscription cleanups
    };
  }, [symbol]); // Triggers execution when dependencies update

  return <p>{symbol}: {price}</p>;
}

2. useContext Global Infrastructure

Context simplifies deep structural application adjustments by broadcasting shared values directly to sub-nodes without manual mid-level property passing.

import { createContext, useContext } from 'react';

const ThemeContext = createContext('dark');

function Toolbar() {
  const theme = useContext(ThemeContext);
  return <div className={theme}>Toolbar Content</div>;
}

3. useRef Access Point

This hook stores mutable references that don't trigger layout updates, making it perfect for targeting direct DOM elements instantly.

import { useRef } from 'react';

function FocusInput() {
  const inputRef = useRef(null);

  const onClick = () => {
    inputRef.current.focus();
  };

  return (
    <div>
      <input ref={inputRef} />
      <button onClick={onClick}>Focus Input</button>
    </div>
  );
}

4. useReducer State Complexities

Perfect for managing advanced multi-step properties. State mutations are grouped inside a predictable reducer function driven by clean action dispatches.

import { useReducer } from 'react';

function reducer(state, action) {
  switch (action.type) {
    case 'increment': return { count: state.count + 1 };
    default: throw new Error();
  }
}

function CounterWithReducer() {
  const [state, dispatch] = useReducer(reducer, { count: 0 });
  return (
    <button onClick={() => dispatch({ type: 'increment' })}>
      Count: {state.count}
    </button>
  );
}

5. Custom Hooks Extraction

Isolate and package redundant component algorithms away cleanly into independent, testable utilities.

function useWindowWidth() {
  const [width, setWidth] = useState(window.innerWidth);
  useEffect(() => {
    const handleResize = () => setWidth(window.innerWidth);
    window.addEventListener('resize', handleResize);
    return () => window.removeEventListener('resize', handleResize);
  }, []);
  return width;
}

6. useMemo Computations

Caches heavy calculations locally so that complex operations skip executing during unrelated component redraws.

import { useMemo } from 'react';

const expensiveValue = useMemo(() => {
  return runHeavyCalculation(data);
}, [data]);

7. useCallback Optimizations

Preserves static callback function instances across component rerenders, stopping unnecessary updates on sensitive sub-components.

import { useCallback } from 'react';

const handleSelection = useCallback((id) => {
  doSomethingWith(id);
}, [dependencies]);

📅 Day 3 — Production Architecture

1. React Router (Navigation)

Enables reliable, smooth page route configurations inside standard single-page applications.

import { BrowserRouter, Routes, Route, Link } from 'react-router-dom';

function App() {
  return (
    <BrowserRouter>
      <nav>
        <Link to="/">Home</Link>
        <Link to="/portfolio">Portfolio</Link>
      </nav>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/portfolio" element={<Portfolio />} />
      </Routes>
    </BrowserRouter>
  );
}

2. API Fetching Layer (Clean Hooks)

Bundle API tracking setups systematically away inside specialized custom hook functions to track loading and failure indicators seamlessly.

function useStocksApi() {
  const [stocks, setStocks] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch('/api/portfolio')
      .then(res => res.json())
      .then(data => { setStocks(data); setLoading(false); });
  }, []);

  return { stocks, loading };
}

3. Global State Architecture (Zustand Example)

Clean global state management stores application-wide values elegantly without forcing heavy Context redraw boilerplate overhead.

import { create } from 'zustand';

const useStore = create((set) => ({
  stocks: [],
  addStock: (stock) => set((state) => ({ stocks: [...state.stocks, stock] }))
}));

4. Error Boundaries

Catch JavaScript syntax runtime crashes safely down inside child component trees before they take down the entire active screen interface.

class ErrorBoundary extends React.Component {
  state = { hasError: false };
  static getDerivedStateFromError() { return { hasError: true }; }
  render() {
    if (this.state.hasError) return <h1>Something broke.</h1>;
    return this.props.children;
  }
}

5. Component Testing (React Testing Library)

Write clear validation tests that assert core visual element shifts from user behavior simulation triggers.

import { render, screen, fireEvent } from '@testing-library/react';
import Counter from './Counter';

test('increments count value', () => {
  render(<Counter />);
  const button = screen.getByText(/Count: 0/);
  fireEvent.click(button);
  expect(button.textContent).toBe('Count: 1');
});

6. Server-Side Rendering Theory (Next.js Layer)

Pre-compiles structural content directly on the server host, returning complete markup early for high performance optimization.

// Standard Next.js server retrieval architecture
export async function getServerSideProps() {
  const data = await fetchPortfolioData();
  return { props: { data } };
}

7. Performance Optimization & Memoization

Lazy loading splits bundling chunks automatically, while React.memo bypasses costly re-evaluation loops if inputs haven't changed.

// Defer bundle assets smoothly with lazy loading
const Dashboard = React.lazy(() => import('./Dashboard'));

// React.memo stops unnecessary sub-component evaluations
const StockRow = React.memo(({ stock }) => (
  <tr><td>{stock.symbol}</td></tr>
));
