React Interview Questions & Answers

🟢 Beginner (Foundations)

1. What is React?
A JavaScript library for building user interfaces using components.
2. What is JSX?
A syntax extension that lets you write HTML-like code inside JavaScript.
3. What are components in React?
Reusable building blocks that define UI and behavior.
4. Difference between functional and class components?
Functional → simple functions with hooks. Class → ES6 classes with lifecycle methods.
5. What is the Virtual DOM?
An in-memory representation of the real DOM that React updates efficiently.
6. What are props?
Read-only inputs passed from parent to child components.
7. What is state?
Internal data managed within a component that can change over time.
8. Difference between props and state?
Props → external, immutable. State → internal, mutable.
9. What is lifting state up?
Moving state to a common ancestor so multiple components can share it.
10. Controlled vs uncontrolled components?
Controlled → React manages state. Uncontrolled → DOM manages state via refs.
11. What is useState?
Hook to add local state to functional components.
12. What is useEffect?
Hook to handle side effects like fetching data or subscriptions.
13. What is useContext?
Hook to consume values from React Context without prop drilling.
14. What is React’s key prop used for?
Helps React identify list items for efficient re-rendering.
15. What is Create React App (CRA)?
A boilerplate tool to quickly set up a React project.

🟡 Intermediate (Practical Use)

16. What is useMemo?
Memoizes expensive computations to avoid recalculation.
17. What is useCallback?
Memoizes functions to prevent unnecessary re-renders.
18. What are error boundaries?
Components that catch errors in child components and show fallback UI.
19. What is reconciliation?
React’s process of diffing Virtual DOM and updating the real DOM.
20. What is code splitting?
Loading parts of the app on demand to reduce bundle size.
21. What is lazy loading in React?
Deferring component loading until needed using React.lazy and Suspense.
22. How to prevent unnecessary re-renders?
Use React.memo, useCallback, useMemo, and proper keys.
23. What is Context API?
Built-in way to manage global state without prop drilling.
24. Difference between Redux and Context API?
Redux → predictable state container. Context → simpler global state sharing.
25. What is hydration in React?
Attaching event listeners to server-rendered HTML during SSR.
26. What is useReducer?
Hook for managing complex state logic using reducers.
27. What is useRef used for?
Persist values across renders or reference DOM elements.
28. Difference between useEffect and useLayoutEffect?
useLayoutEffect runs synchronously after DOM mutations; useEffect runs asynchronously after paint.
29. What is a custom hook?
Reusable function that encapsulates logic using hooks.
30. What is prop drilling?
Passing props through multiple layers unnecessarily.

🔴 Advanced (Deep Dive & Ecosystem)

31. What is React Fiber?
The reconciliation engine enabling async rendering and prioritization.
32. What is concurrent mode in React?
Features that make rendering interruptible and prioritize urgent updates.
33. Difference between synchronous vs asynchronous rendering?
Sync → blocks until finished. Async → can pause, resume, and prioritize.
34. What is hydration in SSR?
Process of attaching React to server-rendered markup.
35. What is useImperativeHandle?
Customizes ref values exposed to parent components.
36. What is memoization in React?
Caching results of computations/components to avoid re-execution.
37. What is React.memo?
HOC that prevents re-rendering if props haven’t changed.
38. Difference between useMemo and useCallback?
useMemo memoizes values; useCallback memoizes functions.
39. What is virtualization in React?
Rendering only visible items in large lists (e.g., react-window).
40. What is tree shaking?
Removing unused code during bundling.
41. What is Redux?
Predictable state container using actions, reducers, and a single store.
42. Difference between Redux and MobX?
Redux → strict, immutable state. MobX → reactive, mutable state.
43. What is Redux middleware?
Functions that intercept actions for logging or async calls.
44. What is snapshot testing?
Capturing component output and comparing against future renders.
45. How do you test React components?
Using Jest and React Testing Library.
46. What is SSR vs CSR?
SSR → server renders HTML. CSR → browser renders after JS loads.
47. What is Next.js?
A React framework that provides server-side rendering (SSR), static site generation (SSG), built-in routing, and performance optimizations.
48. What is server-side rendering (SSR) hydration?
Hydration is the process where React attaches event handlers and makes server-rendered HTML interactive on the client side.
49. What is React’s reconciliation engine (Fiber) designed to solve?
Fiber enables React to break rendering work into units, pause and resume tasks, and prioritize updates for smoother user experiences.
50. What is the difference between controlled and uncontrolled forms in large apps?
Controlled forms are managed by React state, offering predictability and easier validation. Uncontrolled forms rely on the DOM, making them simpler but less consistent for complex apps.
