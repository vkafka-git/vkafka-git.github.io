Architecture Cheat Sheet

Architecture Cheat Sheet (Updated)

  1. High-Level Style
    • DDD microservices (Tax, Immigration, Social Security, Docs)
    • Database-per-service
    • Hexagonal/Clean Architecture
  2. API Gateway
    • YARP API Gateway
    • Dynamic routing, geo-location, rate limiting
    • BFF with Next.js API routes
  3. Frontend
    • Next.js + TypeScript + Tailwind + Zustand
    • Hybrid rendering (SSG/ISR + SSR/CSR)
    • Micro-frontends by domain
  4. Data & Integration
    • Polyglot persistence (MongoDB, SQL/Postgres)
    • Redis caching
    • Event-driven messaging (MassTransit, RabbitMQ, Service Bus)
    • Choreography (Event-Driven): services react to events and publish new ones, no central orchestrator
  5. CQRS
    • Command side → SQL Server (writes)
    • Query side → Cosmos DB (reads)
    • Benefits: scalability, separation, optimized workloads
  6. Mediator Pattern
    • Application layer dispatch (MediatR)
    • Controllers → _mediator.Send(command/query)
    • Pipeline behaviors: validation, logging, authorization
  7. Testing & Quality Assurance
    • Unit Testing: xUnit/NUnit with Moq, fast isolated tests
    • Integration Testing: EF Core InMemory, Testcontainers, validate data flow
    • Load Testing: JMeter, k6, Azure Load Testing, simulate concurrent users
    • Performance Testing: BenchmarkDotNet, App Insights, measure latency and throughput
  8. Azure Durable Functions
    • Orchestration of long workflows
    • Fan-out/fan-in compliance checks
    • Human approvals
    • Resilience via checkpointing
  9. Cross-Cutting Concerns
    • Security: Azure AD, JWT, Key Vault, Zero-Trust AKS
    • Resilience: Polly (retry, circuit breaker, bulkhead isolation)
    • Observability: App Insights, Serilog, Elastic/Kibana, Grafana
    • Scalability of Pods: Elastic scaling via AKS HPA, Cluster Autoscaler, stateless design for horizontal scaling
    • Code Quality Enforcement: StyleCop (coding standards), Roslyn analyzers (custom/static rules), SonarQube (quality gates)
    • Redis Caching: Distributed cache for performance optimization
    • Content Delivery Network (CDN): Azure CDN/Front Door for global edge caching of static assets and API responses
    • API Rate Limiting & Throttling: Protects backend services from overload at API Gateway
    • Secrets Management: Azure Key Vault for credentials and certificates
    • Logging & Tracing: Distributed tracing with OpenTelemetry, correlation IDs across microservices
  10. DevOps & Cloud
    • IaC: Terraform/Bicep
    • GitOps: ArgoCD/Helm for declarative deployments
    • .NET 8 Docker images on AKS
    • CI/CD pipelines: automated builds, tests, scans, SonarQube quality gates
    • Blue-Green / Canary Deployments: zero-downtime release strategies
    • Monitoring & Alerting: Azure Monitor, Grafana dashboards, alerts on latency/errors
    • Autoscaling Policies: HPA for pods, Cluster Autoscaler for nodes, VPA for resource tuning
    • Global Traffic Management: Azure Traffic Manager / Front Door for multi-region routing
  11. Globalization
    • Multi-region Azure deployment
    • Multi-language rendering
    • Country-specific tax formats
  12. Retrospective
    • Regulatory complexity handled via microservice isolation
    • Data sovereignty enforced with database-per-service
    • Contract governance via consumer-driven contract testing
